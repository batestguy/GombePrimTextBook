TEACHER / KEEP WITH THE CHAPTER
Notice and help
Read aloud, observe the action and choose the next step.
P1-01  |  Chapter sample for review
7
Prepare: five large, clean counters. Supervise; use pieces too large to swallow. Read
introductions and story together. A pupil may point, speak or move objects; assess handwriting
separately. Family settings are fictional.
Answers
1: 3. 2: 5. 3: Two separate circles. 4: 1, 2, 3, 4, 5. 5: 4.
6: The middle counter is touched twice. Touch or move each counter once; the correct total is 3.
The spoken labels 1 / 2, 3 / 4 show the wrong count, not the correct quantities.
Fresh check (page 6)
Without showing a model set, ask for 4 counters. Say one number at a time: 1, then 2, then 4.
Ask the child to point to it. Record each response as independent / with help / not yet. Correct
copied numbers alone do not establish recognition.
If you notice this, try this
A dot is skipped or counted twice.
Put counters in a line. Touch one while saying one number.
Recheck: Give a fresh set of 2, then 3. Watch each touch.
The child counts but cannot say how many.
Repeat the last number: 'Three. There are three.'
Recheck: Count a fresh set and ask 'How many altogether?'
Numerals are copied but not recognised.
Match a small set to its number card. Say the number.
Recheck: Shuffle the cards. Ask for 1, then 2, then 4.
Another day: ask for 5 counters and count them. Spread the same counters out. Count again.
Ask, "Did the number change?" No: there are still 5.
Ready for more? Make a row of 4 counters. Rearrange the same counters and count again.
