MATHS WITH FRIENDS
TEACHER GUIDE
FOR THE TEACHER
Teach, notice and return
One chapter teacher: Ms Binta / Female lead / Classroom review pending.
Prototype P1-01 / Teacher edition / Review pending
Start with real objects. Use five large, clean, unbreakable cups. Read pupil text aloud.
Demonstrate slowly with a fresh set of three: one touch and one number word per cup, then
state the total. Introduce the cup pictures and numeral column afterwards. Do not require pupils
to read task labels or remember a slogan before modelling.
Recall through action. On the later pages, first ask what Ms Binta showed them and invite a
demonstration. Wait for a response. If needed, model again and practise together. Observe
counting, stating the total and recognising numerals separately from handwriting. Speaking,
pointing or moving objects are valid responses.
Answer and assessment map (adult IDs only)
P1-01-Q1 / Count the row: Three cups; one touch and one number word per cup.
P1-01-Q2 / Count this group: Five cups, despite their different positions.
P1-01-Q3 / Draw to show how many: Two separate circles, one for each cup picture.
P1-01-Q4 / Write the numbers: The numerals one to five in order; observe independent formation
separately from tracing.
P1-01-Q5 / Show with your hand: Four fingers and the numeral 4. Accept a set of four objects if a hand
response is unsuitable.
P1-01-Q6 / Help Adamu start again: Touch or move each cup exactly once, say one number per cup,
and state three cups. Explain or demonstrate without requiring written prose.
If a child struggles
Skips or repeats: line up the cups; move each counted cup aside. Recheck with a fresh small set.
Cannot state the total: repeat the last number, then ask how many altogether.
Copies but cannot recognise: match cups to a numeral, shuffle the cards and ask again.
Fresh check: ask for four cups, without a model. Name one shuffled numeral at a time. Record
independent / with help / not yet. Later: On another day ask what Ms Binta showed the class. Invite
a demonstration with a fresh small set before showing the model again.
