Explain your check
Read together. Say, point or use your workbook or exercise book.
Read together. Write in this workbook.
Explain how to check 8 + 6 = 14. Use these counters or your own. Tell

total and explain how you know.

A smaller step
Read together. Say, point or use your workbook or exercise book.
Read together. Write in this workbook.
With an adult: count these two counters. Keep two. Touch the one new
counter. Say three. Count all to check.
Now try on your own with three counters and two more. Draw them
here. Write the total. Tell how you counted on.
Remember: say the NEXT number for the first new counter.

The garden-path check
Read together. Say, point or use your workbook or exercise book.
Read together. Write in this workbook.
Use the original eight path counters and five more. Count on as you
move the five. Check by counting all.
The same counters, now joined in one path.
Write the total: 8 + 5 = ______
Tell an adult how you know no path counter was lost or added. All the
original counters must be present.
Without looking back, say how to start counting on. Say what adding
zero does. Explain how to check a total.

Try afresh
Read together. Say, point or use your workbook or exercise book.
Read together. Write in this workbook.
Try on your own. Use your counters or dots. Write a number sentence
and show a check for each story.
Start with five counters. Add seven counters.
Start with two counters. Add zero, then nine counters.

correct number sentence.
