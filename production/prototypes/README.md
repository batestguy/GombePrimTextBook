# Chapter overlays

Follow [CHAPTER-STANDARD.md](../../docs/CHAPTER-STANDARD.md),
[the review protocol](../../docs/CHAPTER-REVIEW.md) and
[the handoff template](../../docs/HANDOFF-TEMPLATE.md).

The current sample is p1-01-v7.json with design-v7.json and the retained v5
assessment base. Earlier overlays are historical experiments. Canonical p1.json,
p2.json and p3.json still describe the legacy edition; preserve stable objective
and question links during migration. Register the exact chapter artifact in
../chapter-reviews.json, reset any affected approvals to pending before editing,
and obtain independent every-task and every-page review before approval.

Draft checks do not certify teaching, mathematics or story logic. Never use a
historical prototype's validation file to approve a revised chapter.
